# 🌸 Peluk — Teman Curhat yang bisa Cerita Bebas, Didengar Hangat

Peluk adalah aplikasi web curhat anonim yang hangat dan empatik, didukung oleh AI (Groq Llama 3.1) untuk memberikan respons seperti teman dekat. Setiap percakapan terjaga konteksnya (nyambung) dan dilengkapi afirmasi positif.

![Tampilan Peluk](Screenshot%202026-05-19%20151547.png)

## ✨ Fitur Utama

- 💬 **Curhat natural** – bahasa Indonesia santai, pakai "aku", "kamu", "sih", "dong", dll.
- 🧠 **Konteks percakapan** – AI mengingat histori chat dalam satu sesi (tidak hilang).
- 🌈 **Pilih mood** – sedih, kesal, cemas, kecewa, lelah, butuh dukungan.
- 🫂 **Afirmasi positif** – setiap balasan disertai 3 afirmasi singkat dan menenangkan.
- 🚫 **Rate limit handling** – jika mencapai batas harian Groq, tampilkan pesan ramah.
- 🎨 **Desain aesthetic** – pastel, glassmorphism, tipografi nyaman, logo besar.
- 📱 **Responsif** – berfungsi baik di desktop maupun mobile.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: HTML5, CSS3 (vanilla), JavaScript (ES6)
- **Backend**: Netlify Functions (serverless)
- **AI**: Groq API (model `llama-3.1-8b-instant`)
- **Deploy**: Netlify (drag & drop atau GitHub)
